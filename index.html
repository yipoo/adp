    使用指南

    从喜欢的界面开始。

    1. 在 Components、Blocks、Templates 中找到设计，直接操作卡片内的 demo。

    2. 点击「查看 prompt」打开详情。复制包含布局、配色、交互、动效与验收标准的 prompt。

    3. 把 prompt 交给 Codex、Claude、Cursor 等工具，补上技术栈、页面用途和真实内容。

    Free 与 Pro 表示内容分级。当前本地版本开放全部预览和 prompt；会员鉴权与支付尚未接入。

    快捷键：/ 搜索 · Esc 关闭窗口。收藏与 prompt 编辑保存在当前浏览器。
    PROMPT WORKSPACE

    让设计，说你们的话。

    在详情中逐项编辑，或通过 JSON 批量导入你们提供的 prompt。用条目 id 对应，未提供的条目保留原内容。

    文件格式：[{ "id": "prompt-composer", "prompt": "你们的完整 prompt…" }]
    导入仅作为文本处理，不执行 HTML 或脚本。

    内置 prompt 为首版编写，可替换成你们的正式内容。
