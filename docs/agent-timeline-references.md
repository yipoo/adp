# Agent Timeline 组件收录说明

调研及本地验证日期：2026-11-10。

本轮新增 10 项 Free 设计（8 个 Components、2 个 Blocks），使目录达到 33 项设计、198 份双语三框架源码。沿用现有 ADP 视觉及源码生成流程，没有引入额外 UI 依赖。全部实现独立编写。

## 收录内容

| 目录 id | 组件 | 本地演示 |
| --- | --- | --- |
| `agent-timeline` | Agent 执行时间线（Block） | 可展开步骤，推进完成数，重置 |
| `tool-call` | 工具调用卡片 | 参数与结果切换，演示完成与重置 |
| `agent-plan` | Agent 计划队列 | 按顺序推进，完成后禁用 |
| `tool-approval` | 工具操作审批 | 操作范围、批准、拒绝与决定锁定 |
| `source-citations` | 来源与行内引用 | 引用与来源同步，摘要及内置资料全文 |
| `subagent-tasks` | 子 Agent 任务卡 | 两个已完成的子任务，展开职责、耗时与结果 |
| `agent-retry` | 失败与重试 | 失败、重试中、成功、跳过与重置 |
| `agent-checkpoint` | 任务检查点 | 选择、确认、取消与恢复预览摘要 |
| `context-usage` | 上下文与用量 | 分组预算、可访问用量条与压缩预览 |
| `trace-waterfall` | Agent 耗时瀑布图（Block） | 同一时间轴的并行跨度、工具筛选、跨度详情 |

## 集成方式与范围

- `data/catalog.json` 是名称、分类、双语说明、prompt 的正式内容源。新条目使用 `Agent Timeline` 分类。
- `src/agent-timeline.js` 独立管理新增演示，经 `src/demos.js` 接入卡片、详情和独立预览。
- `npm run generate:sources` 生成 `sources/<id>/<en|zh>/` 中的 React、Vue、HTML；不要直接修改生成文件。
- 详情页仅显示产品内相关资源，不展示外部设计来源。
- 组件显示可观察的任务步骤和公开摘要，不依赖模型私有内部推理。
- 所有操作都是本地预览，没有模型调用、文件写入、真实审批、真实回滚或计费。用量、费用、时间跨度均为固定示例。
- 真实项目应从服务端接入任务和工具事件；批准决定与执行结果分开处理。失败重试演示仅针对只读检索，不应用来自动重试结果未知的写入。

- React 与 Vue 分别以中英文在 390px 实际挂载及操作，40 项交互检查通过；React 采用 StrictMode，无浏览器运行错误。
- 真实目录入口、8 个 Components / 2 个 Blocks 的分类筛选、详情、prompt 和三种源码切换通过。
- 检查了时间线的 200% 缩放等效布局与减少动态设置；关键桌面、手机截图已人工查看。未进行独立评审。
