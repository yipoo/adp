# ADP 内容站与交互工作台

## 页面与构建

- `/zh/`、`/en/`：原工作台视觉的默认首页。原始 HTML 已包含标题、默认模板列表、分类、类型与独立条目链接；JavaScript 在同一份 HTML 上增强搜索、收藏、真实预览和快捷弹窗。
- `/<lang>/categories/<categoryId>/`：使用稳定英文分类 ID。
- `/<lang>/components/<id>/`、`blocks/<id>/`、`templates/<id>/`：39 个设计的 78 个双语详情页。
- `/<lang>/components/`、`blocks/`、`templates/`：按类型浏览。
- `/studio/`：原有工作台的兼容入口，保留收藏、prompt 编辑、源码切换、批量工具与登录权益；不参与索引。默认首页拥有相同交互能力，并可被索引。
- `/`：默认进入中文首页；历史 `#item=...`、显式语言参数映射到对应新页面，`#library` 等工作台片段继续进入工作台。

`npm run build` 将同一内容源生成为 `dist/`。`npm run build:vercel` 复用这份静态产物，添加现有账单函数，输出 `.vercel/output/`，不维护第二套网页模板。不存在的地址返回真正的 404。部署预览或 `SEO_NOINDEX=true` 构建使用 noindex；本地服务器始终返回 noindex 响应头。

静态页面包含正文、普通链接、独立标题/描述、规范网址、双语互指、面包屑、与可见内容一致的结构化数据及摘要分享图。首页直接使用工作台模板和样式，不为爬虫与普通用户提供不同内容。首页卡片标题链接正常导航，独立的快捷预览按钮继续打开弹窗。SVG 明确标记为设计摘要，不冒充实际运行截图。详情页的演示在用户选择加载时才导入现有渲染代码。

## 单一内容源与稳定身份

`data/catalog.json` 是设计事实与双语公开文章的来源。`data/taxonomy.json` 提供分类名称、介绍和稳定分类 ID。`data/identities.json` 记录已承诺的条目 ID 与类型路径；删除 ID 会构建失败，移动类型必须在 `aliases` 中声明旧的双语地址。更新显示名称不改变 ID 与网址。

每条记录包含 `categoryId` 与 `publicArticle.zh/en`，其中 `useCases`、`limitations`、`integration` 是明确的公开内容。行为说明复用本就公开的 `specs/specsEn`。这些文章逐条描述具体控件的用途与边界，不从付费 prompt 提取，不编造用户案例、测试结果或更新时间。

只有人工确认的实际编辑日期才可填写 `publishedAt`、`updatedAt`。构建不以当前时间伪造更新。没有真实日期时不输出日期结构化数据和 sitemap lastmod。

## 付费与公开边界

`src/content.js` 的 `publicItem()` 使用字段白名单。Free 条目可带公开 prompt；Pro 条目的两个 prompt 字段为空，框架源文件不复制到公共产物。网页、工作台数据、搜索索引均使用相同投影。公开详情包含有用介绍和真实可操作预览，不需要登录。

Pro 完整资源继续通过现有 Lifetime 认证接口返回。公开介绍可以免费读取，设计资源实体按 Free/Pro 标记。不得把完整付费 prompt、源码、鉴权凭据放入 HTML、JSON-LD、搜索文件或分享图。

演示实现仍是公开预览代码，这与已有产品策略一致；“付费导出受保护”不等同于隐藏所有浏览器中的渲染实现。

## 添加和维护条目

1. 在目录中添加稳定 ID、类型、等级、演示配置、双语描述和公开文章。
2. 在身份文件登记 ID 和类型，选择现有 categoryId 或新增完整双语分类。
3. 复用演示实现，运行 `npm run generate:sources` 生成三种实现。
4. 运行 `npm run check`、`npm run build:vercel`、`npm run check:seo`、`node tools/verify-static.mjs`。
5. 实际检查代表性手机/桌面页面、无脚本正文、演示与复制按钮。生成目录不手工修改。

页面地图、分类入口、相关设计、搜索数据、规范网址、语言链接和分享图由构建自动更新。相近条目应先完善差异说明；不要用批量换词创建新的搜索页面。

## 验证范围

`check:seo` 覆盖全部 106 个可索引网址、78 个双语详情正文、内部链接、结构化数据、规范网址、语言配对、站点地图、身份与别名、公开字段和 Pro 边界。`check` 编译全部 234 个源文件。
