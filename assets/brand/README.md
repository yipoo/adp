# ADP identity

The prompt chevron flows into two interface panels: **prompt → interface**.

- Primary blue: `#4057F4`, matching the product accent.
- `adp-icon.svg`: 64 × 64 app icon; `adp-icon.png`: 512 × 512 transparent PNG.
- `adp-logo.svg`: horizontal icon + outlined ADP wordmark; matching PNG at 4× resolution.
- `adp-logo-white.svg` / `.png`: white wordmark for dark backgrounds.
- `adp-symbol-ink.svg` / `adp-symbol-white.svg`: single-color symbol on a transparent background.
- `adp-brand-preview.svg` / `.png`: light, dark, and 16 / 24 / 32 / 48px applications.

SVGs have no embedded fonts, scripts, or external dependencies. Keep the icon proportions and the space between chevron and panels. Below 16px, use a larger icon instead of compressing the detail.
